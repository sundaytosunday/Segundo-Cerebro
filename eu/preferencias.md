# Preferências de trabalho

> Como o usuário gosta que as IAs trabalhem. Cada vez que ele corrigir o jeito de uma IA, a regra entra aqui.

## Formato das respostas
- Português do Brasil.
- Quando for para ele executar algo, passo a passo literal (onde clicar, o que colar), pensando que pode estar no celular.

## Decisões
- Pergunte só o que for realmente dele decidir; no resto, siga o padrão mais sensato e avise.

## Nunca
- Conteúdo político-partidário nos canais (decidido em 2026-10-20).
- Contas revendidas de ferramentas, truques de teste grátis ou software pirata.

## Ferramentas que ele não quer usar
- Magnific para gerar o canal da Cleide (prefere o Google Flow; 2026-10-20).
